# Bundled Media3 decoder extensions

The app bundles one Media3 FFmpeg decoder extension. It is required because the
accepted TCL playback path rejects broken platform MP1/MP2 decoders and falls
back to FFmpeg. Unused AV1, IAMF, and MPEG-H extensions inherited from TVHStream
were removed rather than distributing unidentified native code.

`native-dependencies.json` records the immutable AAR hash, archive layout,
source revisions, build inputs, and redistribution evidence. Run:

```bash
./tools/check-native-libs
```

That command verifies the AAR hash, expected native libraries and ABIs, and
16 KB ELF load-segment alignment.

The stricter release check also requires complete, explicitly approved source,
toolchain, build, license, and corresponding-source evidence:

```bash
./tools/check-native-libs --release
```

Every binary release must additionally include the corresponding-source archive
generated by `tools/build-media3-ffmpeg`; passing the repository check alone is
not permission to omit that release artifact.

## Current inventory

| AAR | Native implementation | Status |
|---|---|---|
| `lib-decoder-ffmpeg-release.aar` | Media3 FFmpeg wrapper with MP1/MP2/MP3 only | Rebuilt and approved from pinned source and toolchains |

The archive contains `armeabi-v7a`, `arm64-v8a`, `x86`, and `x86_64`. Its AAR
metadata requires compile SDK 35 or newer and its manifest declares minimum SDK
23. The product itself requires API 28.

Install those SDK packages, then run:

```bash
ANDROID_HOME=/path/to/android-sdk ./tools/build-media3-ffmpeg
```

The script checks out the exact commits, applies
`patches/media3-ffmpeg-disable-iconv.patch`, builds the four ABIs, and emits the
AAR, native source archive, and checksums. `--disable-iconv` prevents FFmpeg
6.0.1 from treating Android header declarations as linkable `iconv` symbols.
The same patch disables the path-dependent GNU build ID; stripped native code is
otherwise identical, and removing that note makes the final AAR byte-reproducible
across checkout directories. Media3's 16 KB linker alignment remains enabled.

The upstream Media3 helper disables programs, shared libraries, documentation,
formats, devices, filters, post-processing, scaling, Vulkan, and everything not
explicitly enabled. This build adds only `--enable-decoder=mp1`,
`--enable-decoder=mp2`, and `--enable-decoder=mp3`. FFmpeg's configure result is
`LGPL version 2.1 or later`; neither `--enable-gpl`, `--enable-version3`,
`--enable-nonfree`, nor an external codec library is used.
