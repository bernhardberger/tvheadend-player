# Local artifacts

This directory holds ignored local research, screenshots, review evidence, and
session material. Repository instructions must not discover or load it as a
current evidence set.

- `ux-screen-inventory/review/` — historical local UX review sets.
- `ui-inspiration/` — third-party visual research, not product evidence.
- `ai-session-notes/` — retained model prompts, handoffs, decision logs, and
  completion reports that are useful to the owner but are not repository
  authority.

An assignment may use an artifact only when it supplies the exact path and
states whether it is current or historical. Review and redact household data
before publishing any artifact.
